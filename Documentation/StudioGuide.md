# 五面房间版本

默认打开 `Content/RoomShift/RoomShiftStudio.umap`。旧 `RoomShift.umap` 和用户原有修改保留；额外恢复点位于项目上一级的 `output/RoomShiftBeforeFiveFaces/`。

## 玩法

四面墙与天花板上的面板绕自身法线旋转，地板固定。A/B/C 是前、右、左墙；D 是背墙；E 是天花板。1–5 选面，Q/E 转动，空格拼合。底部工具栏可完成同样操作，并提供鼠标撤销、重置、提示和帮助。右键拖动环视，Home 回正。视点固定在 (-80, 0, 150) cm，水平视野 120°，初始仰角 12°；WASD、中键和滚轮不移动或缩放视点。水平可环视 360°，俯仰限制 ±80°，画面保持水平。

建议先做沙发，再做茶几、门和扶手椅，最后处理需要三个面协同的书架、书桌。没有强制顺序；旋转任一共享面会同时移动所有未完成家具的相关碎片。完成的家具从墙面脱离，整体下落 180 cm 并保留在地板上。目标角度见 README。

完成后或想换一局时，点击 NEW MIX 或按 N，随机重新打乱五个面的角度并清空拼合进度。Z 可以撤销这次打乱；R 返回教学起始布局。可以比较同一目标下使用的转动次数。

## 模型与风格

- ArchVis：沙发、茶几、门、扶手椅，以及植物、落地灯和吸顶灯。保留原 UV、贴图和材质。
- 新导入的 OldFurniturePack_01：书架和书桌，保留木材细节。
- 统一环境使用暖灰墙面、木地板、深木色收边和暖光；彩色细环只承担操作提示。
- 六件完整家具切为 14 个片段，输出在 `Content/RoomShift/Studio/Fragments`。切片保持共同源坐标，装配角度下可以精确复原。
- Fab 的组合家具资源保留在 Content 中；本版选用了已导入的 OldFurniturePack 与 ArchVis，而没有把所有风格都混入房间。

完整源模型未被修改。`Tools/create_studio_scene.py` 创建新关卡，若关卡已有正式对象会拒绝覆盖。日常修改请直接在编辑器中操作。切分流程使用 Geometry Scripting（仅编辑器需要），游戏运行使用已保存的静态网格。

## 编辑

World Outliner → RoomShift → Furniture 中可修改模型、材质和变换。保留 Actor 标签 `RS_AUTHORED`、`RS_FACE_n`、`RS_FURNITURE_n`，它们决定运行时归属。更换网格时应保持切片的共同坐标、比例和拼合关系。整体移动家具目标或改变切片数时，需要重新检查目标姿态；代码仍用目标角度判断可拼合，不做几何碰撞识别。

选择 `PreviewCamera` 并 Pilot 可回到房间内预览。所有修改在非 Play 模式完成并保存。运行时鼠标 HUD 不写入关卡。

## 拼合反馈与外设

视角串口命令：`VIEW,30,15` 表示向右转 30°、仰视 15°，桥接自动转换为 UDP view 命令并添加 session/seq。动画期间也可转头。Blueprint 可调用控制器的 SetViewAngles。BNO055 应先校准初始朝向，计算相对姿态并按安装方向映射 yaw/pitch，不能直接使用磁北航向作为游戏正前方。建议用相对四元数和滤波处理传感器数据；真实固件和校准按钮尚未接入。鼠标与传感器同时使用时采用最近到达的输入。可先运行 `python Tools/device_bridge.py --stdin` 输入 VIEW 命令测试。

每次成功拼合触发一次约 0.28 秒的轻微画面震动，按 V 或底部 SHAKE 开关可关闭。兼容标准手柄会收到约 0.22 秒的 force feedback。普通鼠标本身没有震动马达，屏幕微震是当前鼠标试玩的反馈形式。

`Tools/device_bridge.py --serial COM4` 在空闲时也轮询状态，因此用鼠标拼合也能让连接的 Arduino 收到 `HAPTIC,180,140`。completion_serial 用于过滤重复回复；新连接建立基线，不回放旧事件。串口采用缓冲拼行，避免半条消息被误读。

`EncoderOutput.ino` 中 `HAPTIC_PWM_PIN=-1` 默认关闭物理输出。实际接入时配置板子的 PWM 引脚，并通过合适的电机驱动器驱动马达，不直接用 GPIO 带电机。此模板保留 A–E 五路编码器事件接口，具体编码器库、引脚和去抖仍需结合实物设置。

## 验证

编辑器 C++ 构建通过；新版关卡生成成功。无渲染自测覆盖：五轴完整旋转及过程中碎片与地板/天花板的净空、无效输入拒绝、六组装配姿态保持、落地高度、完成后独立于全部墙面、撤销与重置、重新打乱及其撤销、选中边框和反馈事件去重。

`python Tools/test_device_bridge.py` 的五面输入、震动去重、分段串口消息三个测试通过。实体编码器、振动马达与手柄的实际触感尚未实机验证。

公开源码仓库不收录 ArchVis、Fab、OldFurniturePack_01 的原始资产或由其切出的家具网格。完整试玩请使用 v0.2.0 Windows Release 的已烹制程序；要在编辑器中修改新版场景，需在自己的授权项目中取得相应资源并保持原始 `/Game/...` 路径。真实 Arduino、振动马达与 Mac 构建尚未实机验证。
